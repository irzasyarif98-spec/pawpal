# pawpal

PawPal - Pet Adoption & Donation App.
PawPal allows pet owners to put their pets for adoption.

# Setup

To get started, you need to setup your database. Go to your XAMPP folder, then copy our pawpal_db/api to your XAMPP folder.

# API

Input Validation, Image Processing, Location Retrieval (Mobile), and many more!
